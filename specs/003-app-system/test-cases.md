## App 列表与应用市场

### TC-003-001: 从空白状态打开 App 列表

| 项目 | 内容 |
|------|------|
| **前置条件** | 用户已登录桌面；App 列表为空（localStorage `dashboard-desktop-apps` 不存在或不含条目） |
| **步骤** | 1. 点击底部工具条「⊞ App」按钮 |
| **预期结果** | ① App 列表 el-dialog 打开；② 显示"暂无已添加的 App，点击「＋」从应用市场添加"空状态提示；③ 可见「＋」添加应用按钮 |
| **关联 FR** | FR-003-021, FR-003-025 |
| **优先级** | P0 |

### TC-003-002: 通过应用市场添加 App 到列表

| 项目 | 内容 |
|------|------|
| **前置条件** | App 列表已打开；系统中注册了至少一个 App（如 BasicClock） |
| **步骤** | 1. 点击 App 列表中的「＋」按钮；2. 应用市场打开，左侧树显示分类（如"基础应用"）和 App 列表（如"时钟"）；3. 点击"时钟"节点；4. 中间预览区显示时钟实例；5. 右侧配置 form 可编辑标题和分类；6. 点击「添加」 |
| **预期结果** | ① 应用市场关闭；② App 列表中出现"时钟"条目；③ localStorage `dashboard-desktop-apps` 持久化该条目（含 hash 生成的 compId）；④ 刷新页面后条目仍存在 |
| **关联 FR** | FR-003-027, FR-003-028, FR-003-029, FR-003-030, FR-003-022 |
| **优先级** | P0 |

### TC-003-003: 应用市场 — 分类树筛选与导航

| 项目 | 内容 |
|------|------|
| **前置条件** | 系统中注册了多个不同分类的 App |
| **步骤** | 1. 打开应用市场；2. 观察左侧 el-tree 结构（两级：category → App 标题）；3. 点击不同 category 节点（不展开/折叠）；4. 点击不同 App 叶子节点 |
| **预期结果** | ① 分类节点点击不触发选中（无 compName → onNodeClick 提前返回）；② 点击 App 叶子节点后中间预览区切换为该 App 的实时预览；③ 右侧配置 form 更新为选中 App 的 title/category/props；④ 右侧属性配置表单更新为选中 App 的 props 定义 |
| **关联 FR** | FR-003-028, FR-003-029 |
| **优先级** | P1 |

### TC-003-004: App 列表 — 分类筛选

| 项目 | 内容 |
|------|------|
| **前置条件** | App 列表中已有多个不同分类的 App（如"时钟"→基础应用、"网页应用"→基础应用、"计算器"→工具） |
| **步骤** | 1. 打开 App 列表；2. 观察分类标签栏；3. 依次点击"全部"、"基础应用"、"工具"分类标签 |
| **预期结果** | ① 默认选中"全部"，显示所有 App；② 点击"基础应用"仅显示该分类的 App（按分类+名称排序）；③ 点击"工具"显示该分类的 App；④ 分类标签栏包含"全部" + 所有出现的分类（含已注册 AppMeta 的分类，即使该分类下无已添加 App） |
| **关联 FR** | FR-003-023 |
| **优先级** | P1 |

### TC-003-005: App 列表 — 移除已添加的 App

| 项目 | 内容 |
|------|------|
| **前置条件** | App 列表中已有"时钟"条目 |

## App 生命周期

### TC-003-006: 从 App 列表启动 App

| 项目 | 内容 |
|------|------|
| **前置条件** | App 列表中已有"时钟"条目；当前无运行 App |
| **步骤** | 1. 打开 App 列表；2. 点击"时钟"条目 |
| **预期结果** | ① App 列表关闭；② 时钟以全屏叠加层渲染在桌面之上；③ 标题栏显示"时钟"（含 ➖ 最小化按钮和 ❌ 关闭按钮）；④ 底部工具条运行中 App 区域出现"时钟"条目（带运行指示点）；⑤ 桌面 Widget 收到 grid-deactive 事件暂停活性 |
| **关联 FR** | FR-003-009, FR-003-010, FR-003-011, FR-003-014, FR-003-019 |
| **优先级** | P0 |

### TC-003-007: 最小化 App

| 项目 | 内容 |
|------|------|
| **前置条件** | 时钟 App 正在全屏运行 |
| **步骤** | 1. 点击 App 标题栏最小化按钮（➖） |
| **预期结果** | ① App 内容以 opacity 0 + translateY(60px) 动画隐藏（约 0.3s）；② App DOM 节点仍存在（`:class="is-minimized"` 应用）；③ 底部工具条该 App 条目变半透明（opacity 0.55）；④ 桌面 Widget 收到 grid-active 事件恢复活性 |
| **关联 FR** | FR-003-013, FR-003-016, FR-003-019 |
| **优先级** | P0 |

### TC-003-008: 恢复最小化的 App

| 项目 | 内容 |
|------|------|
| **前置条件** | 时钟 App 处于最小化状态（`state: 'minimize'`） |
| **步骤** | 1. 点击底部工具条运行中 App 区域的"时钟"条目 |
| **预期结果** | ① App 恢复全屏显示（opacity 1, translateY 0）；② 工具条该条目恢复不透明度；③ 桌面 Widget 再次收到 grid-deactive 事件 |
| **关联 FR** | FR-003-017 |
| **优先级** | P0 |

### TC-003-009: 关闭 App（通过标题栏）

| 项目 | 内容 |
|------|------|
| **前置条件** | 时钟 App 正在运行（全屏或最小化状态均可） |
| **步骤** | 1. 点击 App 标题栏关闭按钮（❌） |
| **预期结果** | ① App 实例从 DOM 中移除；② 底部工具条运行中 App 条目消失；③ 若已无其他运行 App，Widget 收到 grid-active 事件；④ App 的 Vue 组件实例被销毁 |
| **关联 FR** | FR-003-018 |
| **优先级** | P0 |

### TC-003-010: 关闭 App（通过工具条）

| 项目 | 内容 |
|------|------|
| **前置条件** | 时钟 App 正在运行 |
| **步骤** | 1. hover 底部工具条运行中 App 区域的"时钟"条目；2. 点击出现的 × 按钮 |
| **预期结果** | 等同于 TC-003-009：App 从 DOM 移除，工具条条目消失 |
| **关联 FR** | FR-003-018 |
| **优先级** | P1 |

### TC-003-011: 重复启动同一 App（去重行为）

| 项目 | 内容 |
|------|------|
| **前置条件** | 时钟 App 正在全屏运行 |
| **步骤** | 1. 通过工具条快捷方式或 App 列表再次启动"时钟" |
| **预期结果** | ① 不创建第二个时钟实例；② 已有时钟实例保持在 `state: null`（全屏可见）；③ 时钟实例在 `desktopApps` 数组中移至末尾（z-order 置顶）；④ `desktopApps.length` 不变 |
| **关联 FR** | FR-003-015 |
| **优先级** | P1 |

## 多 App 并存与边缘场景

### TC-003-017: 同时运行多个不同 App

| 项目 | 内容 |
|------|------|
| **前置条件** | App 列表中有"时钟"和"网页应用"两个条目 |
| **步骤** | 1. 启动"时钟"；2. 启动"网页应用" |
| **预期结果** | ① desktopApps 数组包含两个实例（不同 instanceId、不同 compName）；② 网页应用在时钟之上（后打开的 z-order 更高）；③ 底部工具条运行中区域显示两个条目；④ 每个 App 可独立最小化/恢复/关闭 |
| **关联 FR** | FR-003-014, FR-003-018 |
| **优先级** | P0 |

### TC-003-018: 全部 App 最小化后 Widget 恢复活性

| 项目 | 内容 |
|------|------|
| **前置条件** | 时钟和网页应用均在运行（`desktopApps.length = 2`）；Widget 处于 grid-deactive 状态 |
| **步骤** | 1. 最小化时钟；2. 最小化网页应用（此时 `desktopApps.length = 0` 触发 watch → empty 分支） |
| **预期结果** | ① 300ms debounce 后 Widget 收到 grid-active 事件；② Widget 恢复可视交互状态 |
| **关联 FR** | FR-003-019 |
| **优先级** | P1 |

### TC-003-019: 页面刷新后运行实例丢失

| 项目 | 内容 |
|------|------|
| **前置条件** | 时钟 App 正在运行（全屏）；App 列表中有"时钟"和"网页应用"条目 |
| **步骤** | 1. 刷新页面（F5）；2. 登录后观察桌面 |
| **预期结果** | ① 时钟不再运行（desktopApps 为设计上的非持久化状态，刷新后为空）；② App 列表中的条目仍然存在；③ App 列表仍可通过点击重新启动时钟 |
| **关联 FR** | FR-003-014, FR-003-022 |
| **优先级** | P1 |

### TC-003-021: App 列表与 App 组件状态隔离

| 项目 | 内容 |
|------|------|
| **前置条件** | App 列表中有"时钟"条目 |
| **步骤** | 1. 启动"时钟"（App 正在全屏运行）；2. 打开 App 列表；3. 从 App 列表中移除"时钟"条目 |
| **预期结果** | ① 已运行的时钟 App **不受影响**（仍在运行）；② App 列表中"时钟"条目被移除；③ 刷新后时钟不再出现在列表中，但当前运行实例仍存在（直到关闭或刷新） |
| **关联 FR** | FR-003-024 vs FR-003-014（运行实例与列表条目解耦） |
| **优先级** | P2 |
