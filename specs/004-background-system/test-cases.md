## TC-004-001: 打开背景选择面板

**优先级**: P0（核心路径）

**前置条件**:
- 用户已登录并进入编辑模式（`desktopMode === 'editing'`）
- 编辑工具条可见

**步骤**:
1. 点击编辑工具条「背景」按钮
2. 等待面板渲染完成

**预期结果**:
- 全屏模态背景选择面板弹出（`desktop-background-list` 组件渲染）
- 显示标题"更换背景"
- 显示分类页签：全部、暗色系、浅色系、动态
- 显示 embla 水平轮播，含背景卡片
- 显示左右导航按钮（‹ / ›）
- 半透明遮罩层覆盖桌面（`background: rgb(0 0 0 / 40%)`）
- 面板 z-index 高于桌面内容（z-index: 200）

**关联 FR**: FR-004-018, FR-004-019

## TC-004-007: 切换图片背景（暗色系 → 浅色系）

**优先级**: P0

**前置条件**:
- 当前桌面背景为 `dark-001`（暗色系）
- 当前主题为深色模式（`html.dark` 存在）
- 背景选择面板已打开

**步骤**:
1. 点击「浅色系」分类页签
2. 点击 `light-001` 背景卡片
3. 观察桌面变化

**预期结果**:
- 面板自动关闭
- 桌面背景渲染层切换到 `light-001` 的 SVG 图片（`<img>` 元素，`object-fit: cover`）
- 背景切换带有 300ms opacity 渐变过渡
- 主题自动切换为浅色模式（`html.dark` 被移除，`isDark.value === false`）
- `desktopConfig.theme` 更新为 `'light'`
- `desktopConfig.background` 更新为 `{ type: 'image', name: 'light-001', title: '浅色背景01', category: '浅色系' }`
- 桌面配置持久化到 localStorage（`dashboard-desktop-data` 键）

**关联 FR**: FR-004-013, FR-004-017, FR-004-023, FR-004-028, FR-004-029, FR-004-031

## TC-004-010: 背景持久化（刷新恢复）

**优先级**: P0

**前置条件**:
- 用户已选择 `dark-002` 作为桌面背景
- `localStorage['dashboard-desktop-data']` 包含 `background: { type: 'image', name: 'dark-002', title: '暗色背景02', category: '暗色系' }`

**步骤**:
1. 刷新浏览器页面（或关闭后重新打开）
2. 等待桌面加载完成

**预期结果**:
- `desktopConfig.background` 从 localStorage 加载，值为 `{ name: 'dark-002', ... }`
- `desktop-background` 渲染层从 `backgroundMetas['dark-002']` 解析实际图片 URL
- 桌面显示 `dark-002` 的 SVG 背景图
- 背景持久化数据中**不包含**实际文件路径或 Vite 哈希 URL

**关联 FR**: FR-004-028, FR-004-029, FR-004-030
